## Как начать новый чат

### Вариант А: Claude Code (claude.ai/code, этот репозиторий подключён)

`CLAUDE.md` загружается **автоматически**, но только если он есть в ветке, с которой стартует сессия (обычно `master`).
Поэтому эти файлы должны быть **влиты в `master`**.

Первое сообщение в новом окне:

```
Прочитай CLAUDE.md и docs/05-PROGRESS.md. Сейчас я работаю над: <что делаешь>.
Нужно: <что хочешь получить>.
```

Если задача про оплату, добавь: «и docs/04-PAYMENT.md». Если про защиту: «и docs/06-DEFENSE.md».

### Вариант Б: обычный чат claude.ai (без доступа к репозиторию)

Прикрепи файлы `CLAUDE.md`, `docs/01-TZ.md`, `docs/05-PROGRESS.md` (и по теме `02`, `03`, `04`) и напиши:

```
Это мой учебный проект на Laravel. В файлах ТЗ, правила и текущий прогресс.
Отвечай на русском и объясняй решения так, чтобы я мог их защитить.
Задача: <что нужно>.
```

## Как поддерживать документы актуальными

- Закончил фичу: обнови статус в `05-PROGRESS.md` и, если менялись маршруты, `03-API.md`.
- Принял важное архитектурное решение: допиши его «почему» в `02-ARCHITECTURE.md` или вопрос в `06-DEFENSE.md`.
- Можно просто попросить Claude: «обнови документацию после этой фичи».
